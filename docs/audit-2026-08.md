## Data schemas

### `data/pl_data.js`

Auto-generated by `data/build_pl_data.py`. Four top-level `const`s.

```js
SUSPENSION  {kind:"ladder", cumulative:true, review:20,
             rungs:[{at:5,ban:1,by:19},{at:10,ban:2,by:32},{at:15,ban:3,by:null}]}
```

```js
CLUBS[20]   {short, name, img, basis, ca, caH, caA, fm, squad}
```

| field | meaning |
|---|---|
| `short` | three-letter code, the join key everywhere |
| `basis` | `"PL"` or `"EFL"` — Championship-basis for promoted clubs |
| `ca` / `caH` / `caA` | cards against per match, overall / home / away |
| `fm` | fouls per match |
| `squad` | squad size |

```js
PL_PLAYERS[664]  {c, n, p, min, yc, rc, y, f, fw, r, ls, b}
```

| field | meaning |
|---|---|
| `c` `n` `p` | club short, name, position group |
| `min` `yc` `rc` | minutes, yellow count, red count |
| `y` `f` `fw` | yellows / fouls committed / fouls won, all per 90 |
| `r` | risk score — `(y × 2) + f`, kept as a ranking |
| `ls` | low-sample flag |
| `b` | basis, `"PL"` or `"EFL"` |

```js
REFS[22]  {n, region, matches, ypg, red, pen, fpg, cpf}
```

`ypg` yellows per game, `red` reds per game, `fpg` fouls per game, `cpf` cards
per foul, `matches` the sample behind them.

### `data/pl_fixtures.js`

```js
PL_FIXTURES[380]  {id, d, r, h, a, ref, st}
```

API-Football fixture id, ISO kickoff, round, home and away short codes,
referee name (`null` until appointed), status.

The Championship and La Liga files carry the identical shape under
`EFLC_*` / `LALIGA_*`.

## Reachability from the working environment

Decisive for anything that scrapes.

| Host | Result |
|---|---|
| `raw.githubusercontent.com` | **200** — the football-datasets mirror works |
| `git clone` (github.com) | **works** |
| `github.com` (HTML) | 400 via the proxy |
| `www.football-data.co.uk` | **unreachable** |
| `fbref.com` | **unreachable** |

This is why `build_refs.py` already tries the GitHub mirror before the origin,
and it means an FBref leg could only ever be exercised in CI.

## Column names, verified against the live CSV

The brief asked for these to be checked rather than assumed. From
`datasets/football-datasets`, Premier League, season 2425:

```
1 Date  2 HomeTeam  3 AwayTeam  4 FTHG  5 FTAG  6 FTR  7 HTHG  8 HTAG  9 HTR
10 Referee  11 HS  12 AS  13 HST  14 AST  15 HF  16 AF  17 HC  18 AC
19 HY  20 AY  21 HR  22 AR
```

All seven the pipeline needs — `Referee`, `HF`, `AF`, `HY`, `AY`, `HR`, `AR` —
are present under exactly those names.

## Gap summary

**Already built** (the brief assumed otherwise): the football-data.co.uk
pipeline, venue-split team rates, the referee table, per-90 player rates, the
Championship-basis adjustment, scheduled regeneration with loud validation,
Git deploys, calibrated card probabilities via a shrinkage-and-hazard model,
fair odds and de-vigged market probabilities, and a walk-forward backtest.

**Genuinely missing:** lineup confirmation, manual odds entry and edge, a
fitted team-level booking model, an opponent fouls-drawn term, a written
backtest report, a single pipeline entry point, two of the four named
validations, `aria-sort` on eight headers, 16 and 32px icons, and sparklines on
two of the three desks.

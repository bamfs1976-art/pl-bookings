## Source data note

Player and club form via ScoutingStats (Sportmonks). Referee data from public sources. Built for research, not a betting guarantee.

Permitted data sources are: the MIT-licensed [epldata](https://github.com/pssguy/epldata) package, the [DataHub English Premier League mirror](https://github.com/datasets/football-datasets) of football-data.co.uk (PDDL), [openfootball](https://github.com/openfootball) (CC0), and the official FPL API through this site's own proxy. **Nothing here is fetched, scraped or derived from FBref, WhoScored, FootyStats, Understat or any bookmaker.** Where a feature needs data only those carry, it takes the number by hand and says so — the promoted clubs' fouls-drawn figure goes in through the Import view, and the per-player backtest simply does not run. The full position is in the app's **Sources & licences** view.

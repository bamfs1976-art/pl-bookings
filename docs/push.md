# Watchlist alerts (Web Push)

> Moved unchanged from the old README.md on 8 September 2026 (the "Watchlist alerts" bullet of "What it is"; the design record is in decisions.md, item 3 of the 2026-08-01 review). The README is now an orientation page; this file keeps the full prose.

- **Watchlist alerts.** Two notifications, both about players you have starred, both only useful on the day they change. **A referee appointed** to one of their fixtures: officials are published about a week before a round, and the appointment moves every booking probability in that fixture through the referee factor — the largest multiplier the desk applies. Turn alerts on under My watchlist and you get one notification per fixture involving a player you follow, as soon as the official is named, plus a separate, louder one if an appointment is later *changed*. And **one caution from a ban**: the desk has always shown the suspension ladder, but only to someone looking at it. That alert uses the same `PLDCore.nextSuspension` the page prices with rather than a second copy of the rule — an English rung expires, so a player on four cautions after his club's 19th match is *not* one from a ban, and a naive count would warn about a suspension that cannot happen. It says the rung, what the next card costs, and how many matches are left before the cut-off. Web Push, so it works on the installed PWA with no app store. Off by default and offered only once you have starred someone: the browser gives a site exactly one permission prompt, and asking before there is anything to alert on wastes it. Optional — without `VAPID_*` set the desk never offers it. Setup: `node scripts/gen-vapid.mjs`, then `supabase/plb_push.sql`.
